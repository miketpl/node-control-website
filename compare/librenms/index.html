LibreNMS is a fully featured, open-source network monitoring system that many engineers already self-host. Its public site describes automatic discovery, alerting, distributed polling, an API, bandwidth billing, and mobile apps, with optional integration to config-backup tools such as Oxidized and RANCID.

After 14 days, Free stays for up to 25 devices. That includes an L2 topology map of up to 10 nodes, Config Backup, Save Config, Find Device on one switch at a time, an inventory report, a file-transfer tab and a multi-vendor terminal. macOS and Windows. L3 and WAN maps, Watcher of The WAN, compliance and Config Push are in the 14-day trial and in Professional. Monitor, Discover, IPAM, the Firewall Analyser and the Meraki Configurator stay as example views in the trial. They are not operational on a real network until Professional.

These two products overlap, but they are not the same kind of tool. LibreNMS is a server you operate, usually on Linux or in Docker, that keeps polling the estate. Node Control is a desktop app. One of the core ideas behind it was that the map, the backups and the inventory should live on the laptop you are already using, without you having to stand up a monitoring server first.

If you want a free, always-on NMS with SNMP discovery, distributed polling and a community around alerting and billing, LibreNMS is built for that. If you want a desktop tool with an L2 map of up to 10 nodes, on-demand config backup and a terminal in the same app, that is the Free Edition. The 14-day trial, and then Professional, add compliance and Config Push. Discover and Monitor become operational on Professional.

When to choose each

Choose LibreNMS when you want a free, open-source monitoring system you can host yourself, with SNMP-based auto-discovery, alerting, distributed polling, and the option to bolt on Oxidized or RANCID for config versioning. Choose it too if you need a mobile app, bandwidth billing, or to scale polling across a large estate without buying a per-device commercial licence.

Choose the Node Control Free Edition when you want an L2 map of up to 10 nodes, on-demand config backup, Find Device on one switch at a time, inventory and a multi-vendor terminal on your laptop, for up to 25 devices, and you do not want to run a monitoring server to get those jobs done. Choose the 14-day trial when you also want to try L3 and WAN maps, Watcher of The WAN, compliance, Config Push and the other Engineer tasks and reports. Choose Professional when you need Discover, Monitor, IPAM, the Firewall Analyser or the Meraki Configurator to be operational on a real network, or you want API Explorer, in the same desktop app.

They can be used together. LibreNMS can poll and alert around the clock. Node Control can sit on the laptop for SSH, on-demand backups and maps. LibreNMS already documents integrations with Oxidized and RANCID if you want scheduled config collection on the monitoring server as well.
