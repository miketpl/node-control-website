SolarWinds Network Performance Monitor and Network Configuration Manager are the tools a lot of network teams already run for fault monitoring and for config backup, change tracking and compliance. This page sets Node Control next to those two products, using only what each of us publishes.

After 14 days, Free stays for up to 25 devices. That includes an L2 topology map of up to 10 nodes, Config Backup, Save Config, Find Device on one switch at a time, an inventory report, a file-transfer tab and a multi-vendor terminal. macOS and Windows. L3 and WAN maps, Watcher of The WAN, compliance and Config Push are in the 14-day trial and in Professional. Monitor, Discover, IPAM, the Firewall Analyser and the Meraki Configurator stay as example views in the trial. They are not operational on a real network until Professional.

One of the core ideas behind Node Control was to keep the work on the engineer's laptop. Configs, inventory and maps stay on your machine. SolarWinds NPM and NCM are self-hosted monitoring and configuration-management products, built to run as a platform rather than as a desktop app, and they are also offered as part of SolarWinds Observability Self-Hosted.

They are not like-for-like. NPM is a continuous SNMP monitoring system, with path visualisation, historical baselines and capacity forecasting. NCM is a scheduled config-management and compliance product, with published support for audits such as DISA STIG, PCI DSS, SOX and HIPAA. Node Control is a laptop app for maps, backups you run yourself, and terminal work. Compliance and Config Push are in the 14-day trial and in Professional. Discover and Monitor become operational on Professional. If you need a 24-hour NOC platform, NPM and NCM are built for that job. If you want a desktop tool you can download and use on a small estate for free, that is the Free Edition.

When to choose each

Choose SolarWinds NPM when you need always-on, multi-vendor fault and performance monitoring, hop-by-hop path visualisation, historical baselines and capacity forecasts, and you are prepared to run a self-hosted platform. Choose NCM when you need scheduled config backups, formal compliance reports against the standards SolarWinds lists, change alerts, and bulk config deployment across a large estate.

Choose the Node Control Free Edition when you want an L2 map of up to 10 nodes, config backups you run yourself, Find Device on one switch at a time, inventory and a multi-vendor terminal on a Mac or Windows laptop, for up to 25 devices, without standing up a server. Choose the 14-day trial when you also want to try L3 and WAN maps, Watcher of The WAN, compliance, Config Push and the other Engineer tasks and reports. Choose Professional when you need Discover, Monitor, IPAM, the Firewall Analyser or the Meraki Configurator to be operational on a real network, or you want API Explorer, and you want that work to stay on the laptop.

It is reasonable to run them together. NPM can keep watching the estate while Node Control is used for terminal work, on-demand backups and maps. This page is not telling you to rip out SolarWinds.
