Tasks

Topology maps, config backup, compliance, config push, terminals, monitor, the firewall rule analyser, IPAM, and the other tasks.

Layer 2 topology map — NodeControl Docs

L2 Topology Builder reads MAC address tables, LLDP neighbours, and CDP on Cisco, and draws switch-to-switch links. It runs on Free, Pro, and the AI edition.

Layer 3 topology map — NodeControl Docs

L3 Topology Builder reads routing tables, OSPF, and BGP, and draws which routers and firewalls peer. On Pro and the AI edition. Included for the first 14 days of the trial, then it needs Pro. On Free after the trial it is greyed out.

WAN topology map — NodeControl Docs

Watcher of The WAN draws cross-site links: routers, firewalls, and SD-WAN edges. On Pro and the AI edition. Included for the first 14 days of the trial, then it needs Pro. On Free after the trial it is greyed out. Safe Mode keeps it listed.

Config Backup and Save Config — NodeControl Docs

Config Backup and Save Config run on Free, Pro, and the AI edition. Config Backup is allowed in Safe Mode. Safe Mode hides Save Config.

Config Compliance — NodeControl Docs

Config Compliance Audit checks selected devices. Remediation is Cisco IOS, IOS-XE, and NX-OS only. On Pro and the AI edition. Included for the first 14 days of the trial, then they need Pro. On Free after the trial both tasks are greyed out.

Config from File — NodeControl Docs

Config from File sends a file's lines to the devices you ticked. Lines go verbatim, with no placeholders. On Pro and the AI edition. Safe Mode hides the task.

Discover Variables — NodeControl Docs

Discover Variables reads a few facts off each device and stores them on the library row. It is read-only. On Pro and the AI edition. Included for the first 14 days of the trial, then it needs Pro. On Free after the trial it is greyed out.

Network Discovery — NodeControl Docs

Discover walks CDP and LLDP from a seed IP and maps devices not yet in the library. On Pro and the AI edition. The trial shows a clickable example view. It is not operational until Pro.

Lab Export — NodeControl Docs

Lab Export turns a saved Discovery or L2 topology into a Cisco CML 2.10 or EVE-NG Community 6.2 lab. Nothing connects to a device. On Pro and the AI edition.

Find Device — NodeControl Docs

Find Device takes a MAC, or an IP from ARP, and names the switch port. On Free you start from one switch. Pro starts from the core switches at each site.

Verify Device Types — NodeControl Docs

Verify Device Types re-runs device type detection on the library, or a subset. On Pro and the AI edition. Included for the first 14 days of the trial, then it needs Pro. On Free after the trial it is greyed out. Safe Mode leaves it listed.

Config Push — NodeControl Docs

Push commands to switch ports from a file, with a preview, safety exclusions, and revert. Pro and AI. Full support is Cisco IOS, IOS-XE, and NX-OS.

Packet Capture — NodeControl Docs

Packet Capture runs an IOS-XE Embedded Packet Capture, copies the file locally, and opens it in Wireshark. Cisco IOS and IOS-XE only. On Pro and the AI edition.

File Transfer — NodeControl Docs

The File Transfer page is on Free, Pro, and the AI edition. The Engineer task is Pro and AI. Its local server speaks SFTP and SCP, on port 2222 by default.

SSH Terminal — NodeControl Docs

SSH Terminal opens an interactive session to a library device, from that device's row. It is on Free, Pro, and the AI edition. It is not an Engineer task.

Serial console — NodeControl Docs

Serial console on the Engineer tab, beside SSH and HTTPS. USB serial, Send Break, paced paste, log to file. Hidden in Safe Mode.

Local network terminal — NodeControl Docs

Terminal, on the Engineer log header, runs local networking commands only: ping, traceroute, and dig. There is no shell. It stays visible in Safe Mode.

Monitor — NodeControl Docs

Monitor polls interface counters, CPU, memory, and environment over SSH, with graphs and threshold alerts. On Pro and the AI edition. The trial shows a clickable example view. It is not operational until Pro.

Firewall Rule Analyser — NodeControl Docs

Firewall Rule Analyser is a PAN-OS tool on Pro and the AI edition. Load a config file, edit standards, and analyse. The trial shows a clickable example view. It is not operational until Pro.

IPAM — NodeControl Docs

IPAM tracks subnets and how much of each was seen in use. The list is the Site Subnets report. On Pro and the AI edition. The trial shows a clickable example view. It is not operational until Pro.

Meraki Configurator — NodeControl Docs

Meraki Configurator changes SSIDs and RF profiles in one pass via the Dashboard API. The trial shows a clickable example view. It is not operational until Pro.
