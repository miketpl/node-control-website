# Config Backup and Save Config

**Config Backup** and **Save Config** are Engineer tasks. Both run on **Free**, **Pro**, and the **AI** edition.

On Free, the Task list that runs is:

- **None**
- **L2 Topology Builder**
- **Config Backup**
- **Save Config**
- **Find Device**

Every other task is greyed out and reads **Upgrade to Pro**.

## What each one is

**Config Backup** takes a copy of the device configuration.

**Save Config** writes the running configuration into the device's saved config.

## How to start one

1. Open **Engineer**
2. In **Task**, choose **Config Backup** or **Save Config**
3. Click **Run**

The screens after Run — what you confirm, and where a backup file is written — are not written up here. Those steps still need a check against the current build.
