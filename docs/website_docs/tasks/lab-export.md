# Lab Export

> On **Pro** and the **AI** edition. Free does not include Lab Export.

Lab Export turns a saved Discovery or L2 topology, plus an optional L3 topology and a Config Backup folder, into a lab for Cisco CML 2.10 or EVE-NG Community 6.2.

Start it from the **Lab Export** button on the Discover tab, or from the Tasks list.

Before the export, a summary shows the node count, the estimated memory, any placeholder nodes and why, the links left out, and the images to check on your lab server.

Nothing connects to a device. It is also available in Safe Mode.
