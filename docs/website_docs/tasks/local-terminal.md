# Local network terminal

The **Terminal** button is on the log header. It is on Free and Pro. It stays visible in Safe Mode.

## What it is (no shell)

It is a local network terminal. There is no shell. The commands are networking commands only.

## Commands you can run

- ping
- traceroute / tracert
- mtr
- pathping
- nslookup
- dig
- arp
- netstat
- routes
- ifconfig / ipconfig
- tcping

## Safe Mode

**Terminal** stays visible in Safe Mode.
