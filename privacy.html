Privacy

This notice describes personal data used by the Node Control website, the Free Edition download, the Professional subscription, and the desktop app when it talks to the licence server at api.nodecontrol.io. Node Control is a product of The Promised Lan Limited.

Device configs, topology, and credentials stay in the app on your computer. They are not sent to the licence server. The licence server does receive the categories on this page.

Purposes

The lawful basis depends on the use.

  • Contract: licences, downloads, and the service emails that go with them.
  • Legitimate interests: security, rate limiting, and aggregate usage statistics.
  • Legal obligation: billing records.

Those uses cover the following.

  • Send the verification code, and issue and check a Free licence.
  • Run a Professional subscription, including the licence key and the payment record.
  • See which computer a licence is active on, and confirm a move to another computer.
  • Tell the app when a newer build is published.
  • Send service email. That includes verification codes, licence keys, device-move codes, a link to manage a subscription, and a product notice such as a version that will stop working.
  • Count which links people follow to the Free form, and which installer downloads start.
  • Store usage counts you choose to send, linked to the licence.
  • Limit repeated requests.

Name, email, and platform are required for a Free licence. Company is optional. If you register an install, name and email are required. Organisation and role are optional. Usage statistics can be turned off. The licence still works if they are off.

Free download form

  • Name
  • Email
  • Platform
  • Company, if you enter one

These are stored in the licence database on servers the company operates. The 6-digit verification code is stored with that request until you enter it, or until it expires. The default expiry is 72 hours. After you verify, that field is replaced with the time you verified. The rest of the row stays, including the free licence code.

The form also sends the campaign tags in the link you followed (utm_source, utm_medium, utm_campaign), the host name of the site that referred you, and the path of the page you are on. These are read when you submit. They are stored on the same licence row. They are not stored in a cookie or in the browser.

When the site starts an installer download, or you click a download link, it records the platform and whether the download was started automatically or from a click. That record is stored against the licence, with the time. It does not include an IP address. If that call fails, the download still starts.

IP addresses

The free-download request stores the address of the connection the API sees. The API is reached through a Cloudflare tunnel, so that stored address is the tunnel, not your public IP address.

Rate limits use the client address Cloudflare sends. That address is stored only as a hash, together with a hash of the licence key or install id where the limit needs one. Those hashes are deleted after about two days. A failed licence check is counted the same way.

Usage statistics do not include an IP address.

The app and the licence server

The app checks the licence with api.nodecontrol.io. A check sends the licence key, a random install id, the app version, the OS family, and the CPU architecture. The server stores the install id, platform, architecture, the time the computer was activated, and the time it was last seen. One computer is active on a key at a time.

Moving the key to another computer is confirmed by an email code, and is limited to two moves in 30 days. The server stores the previous install id, the new install id, and the time. The code itself is stored as a hash, with the email address, until it is used or it expires. A device-move code expires after 15 minutes. Expired codes are deleted when database maintenance runs.

A licence can be revoked.

If you register the install, we store the name, email, organisation, and role you enter, with the app version, OS family, OS major version, architecture, and install id. A copy of that registration, including the last four characters of the licence key, is emailed to support@nodecontrol.io.

A crash log is written on the laptop. The licence server does not upload it. If you email the file to support, that message is ordinary support mail.

Usage statistics

If you leave usage statistics on, the app sends counts for that session: how long it ran, how many connections it opened, how many errors it counted, and counts of tasks such as topology, backup, and ping. It also sends the app version, OS family, OS major version, and architecture. The row is stored against the licence and the install id. It is not anonymous.

The server drops a user name, company, hostname, or machine id if the app sends one. The stored counts do not include device configs, hostnames, IP addresses, or the contents of the network.

The app asks at first launch. You can turn this off in Settings. While it is off, the app is not supposed to send these counts. You can delete the session rows from the app, or by emailing privacy@nodecontrol.io.

Session rows are kept for 365 days, which is the current server setting, then folded into monthly totals. The monthly totals are edition, version, OS family, and the counts. They do not include the licence or the install id. We delete or anonymise those totals on request, or periodically.

Usage statistics are kept on the basis of legitimate interests. They are aggregate product statistics. While they are session rows they are linked to the licence. You can turn them off, and you can object.

Update checks

An update check sends the licence key and install id so the server can answer, and it updates the last-seen time on that computer. The statistic that is kept is a daily count of edition, platform, and version. The key and the install id are not written into that count. The code does not delete those daily counts.

Professional subscriptions

Stripe takes the card payment. We store the email address, the name if Stripe sends one, the Stripe customer id, the subscription id, the checkout session id, the plan, the status, whether the subscription cancels at the end of the period, and when the period ends.

The card number is not stored in the licence database. The billing address and tax ID are entered on Stripe's page. They are not columns in the licence database.

The Professional key is stored as a hash, with an encrypted copy so the same key can be emailed again. The welcome email contains the key.

Service email

We email you when the product needs to: a verification code, a licence key, a device-move code, or a link to manage a Professional subscription.

The licence server can also send a product notice, for example that a version will stop working. Each notice has an unsubscribe link. Opening it records that this licence has opted out. The record is the licence and the time. It does not store your email address. We also record which notice template was sent to which licence, and when. That record does not include your email address either. The same template is not sent to the same licence twice.

Unsubscribing stops further product notices. It does not stop verification codes, licence keys, or device-move codes.

There is no promotional or marketing list. The only emails we send are service emails. Each product notice has an unsubscribe link.

Who else receives data

  • Cloudflare serves the website in front of GitHub Pages, and the licence API is reached through a Cloudflare tunnel. Cloudflare sees the connection, including the IP address and the page or API address.
  • GitHub Pages hosts the website files.
  • GitHub hosts the installer files. Your browser downloads the installer from GitHub, so GitHub sees that download. The licence server also asks GitHub for release details, using its own token.
  • A legacy switch can copy a free licence code to a file on GitHub. That file contains codes, not names or email addresses. The same switch can copy a Professional email address to a GitHub allow-list. The switch is off unless it is turned on.
  • Stripe processes the Professional payment, as above.
  • Email is sent by our email delivery provider, over SMTP.

This site does not load an analytics script, an advertising pixel, or a similar tracker. The typeface is served from this site.

How long we keep it

  • Usage-statistics session rows: 365 days, then monthly totals that are not tied to a licence. We delete or anonymise those totals on request, or periodically.
  • Update-check totals are counts of edition, platform, and version. They are not tied to a person. We delete or anonymise them on request, or periodically.
  • Rate-limit hashes: about two days. Maintenance removes them.
  • An unverified sign-up: we keep it for 30 days. The 6-digit code expires after 72 hours. We delete or anonymise the sign-up on request, or periodically.
  • An expired email code: we keep it for 30 days. A device-move code expires after 15 minutes, and maintenance removes expired codes when it runs. We delete or anonymise any that remain on request, or periodically.
  • Licence and registration records, including the computer a licence is active on and the record that a product notice was sent: we keep them while the licence is active, and for 2 years after it ends. We delete or anonymise them on request, or periodically.
  • Stripe and billing records: we keep them for 6 years, for UK tax. We delete or anonymise them on request, or periodically.

Cookies and local storage

The scripts on this website do not set a cookie, and they do not use local storage or session storage. The Free form reads the page address at the moment you submit.

Professional checkout happens on Stripe's website. Stripe's own cookies apply there.

Security

The website and the API are served over HTTPS, through Cloudflare. Professional keys are encrypted in the licence database. Device-move codes are stored as hashes. The free licence code is stored so the app can be checked.
