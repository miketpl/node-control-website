What the free download form collects

  • Name
  • Email
  • Platform
  • Company, if you choose to enter one

We use this to send the verification code, and to issue and manage the free licence.

Where it is kept

The details are stored in a licence database on servers the company operates. The verification email is sent through an SMTP provider.

The app checks the licence with our server at api.nodecontrol.io.

GitHub hosts the installer files. This website is served through GitHub Pages and Cloudflare. Cloudflare proxies the API.

Transfers of personal data outside the UK, including via the SMTP provider, GitHub, and Cloudflare: [PLACEHOLDER: international transfers]

Analytics and advertising

This website does not load an analytics or advertising script. The pages and scripts in this site were checked. There is no analytics tag, advertising pixel, or similar tracker.

When you request the Free Edition, the form also sends the campaign tags in the link you followed (utm_source, utm_medium, utm_campaign), the host name of the website that referred you, and the path of the page you are on. These are read from the page address when you submit. Nothing is stored in a cookie or in the browser. We store them with your request so we know which channels people find Node Control through. We use them only in totals. They are kept for the same period as the rest of that request.

When the site starts an installer download, or you click a download link, it records the platform and whether the download was started automatically or from a click. That record is stored against your licence, with the time. If that call fails, the download still starts.

In the app

The licence check and device activation send the licence key, a random install id, the app version, and the OS family to api.nodecontrol.io.

Update checks send the same kind of request, so the app can tell you when a newer build is published.

If you register the install, we store the name, email, organisation, and role you enter, with the app version and OS family, in the licence database. An alert email goes to support@nodecontrol.io.

Usage statistics are counts of features used, the session length, the app version, and the OS family. They are linked to the licence, so we can see how a licence uses the product. They do not include device configs, IP addresses, hostnames, or the contents of the network. The app asks at first launch and the choice can be changed in Settings. While it is off, the app sends nothing. Per-user rows are kept for 12 months and then kept only as aggregate counts. You can delete the per-user rows from the app, or by emailing support@nodecontrol.io.
