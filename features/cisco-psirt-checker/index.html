Cisco PSIRT checker for the software you run

The Security Audit report in Node Control is a Cisco PSIRT checker. It reads the running software on each device in scope and lists published Cisco security advisories for that version, grouped by severity. Professional is £25 a month or £255 a year, with no per-device fees. The report is in the 14-day trial, with no card needed and no device cap, and it stays in Professional. After 14 days, Free remains for up to 25 devices, but it does not run this report.

The problem a PSIRT check has to solve

Cisco publishes a large advisory list. The useful question is which advisories apply to the software you are actually running, on the hardware you actually have. A version-only match can still include advisories written for other platforms on the same release. You want those called out, not mixed into the confirmed counts, and a report you can export or email.

How Node Control does it

Open Reports, choose Security Audit, set the scope, and run. The report connects to each device in scope, reads the running software, and queries Cisco's openVuln API with the version string normalised to the form that API accepts. Advisories are grouped by severity. Each advisory names the devices it applies to. Non-Cisco devices are skipped.

A Cisco IOS vulnerability audit is one of the searches this report answers, but the check is not limited to IOS. On Cisco IOS, IOS-XE and NX-OS, Security Audit is listed as a supported report. It is not supported on Cisco ASA. IOS-XR is not a supported platform in Node Control.

Cisco indexes many advisories by software release alone. An advisory written for other hardware on that same release is not hidden. It is marked platform mismatch, sorted below the confirmed matches, and kept out of the confirmed High, Medium and Low counts. A missing product list is called out, not treated as a clean pass. If the product list is only a software train but the title names hardware, the title is what gets checked.

You can turn on an optional baseline section. In the same session the report pulls the running config and checks it against your hardening template, using the same engine as Config Compliance. The report is for reading the result; the task is for pushing fixes. The HTML report has Export CSV above each table, and you can email it. If the email is skipped, the log says why.

Built-in AI, with a provider you bring and your own API key, can add an optional AI Summary. It is off on a fresh install, and the PSIRT checks do not depend on it. Vuln Plan is on the AI edition only, which is not yet available to buy. Professional does not have it.

What you get

A Cisco PSIRT report in the 14-day trial and in Professional: advisories for the software you actually run, from Cisco's openVuln data, grouped by severity, with a platform check, an optional hardening baseline, and CSV or email export. Professional is £25 a month or £255 a year, with no per-device fees. After the trial, Security Audit stays on Professional. Free keeps the Inventory report only, for up to 25 devices.

Requirements and supported platforms

The app runs on macOS and Windows. Security Audit runs in the 14-day trial, on Professional, and on the AI edition. Free does not run it after the trial. Non-Cisco devices are skipped. Supported platforms here are Cisco IOS, IOS-XE and NX-OS. Cisco ASA is not supported for this report, and IOS-XR is not supported. The report queries Cisco's openVuln API, so it is not an offline-only check.

FAQ

Is the Cisco PSIRT checker in the 14-day trial?

Yes. Security Audit is included for the first 14 days, with all other reports and every Engineer task, and no device cap. No card is needed. After 14 days it stays on Professional. Free does not run this report.

Does it use Cisco's openVuln data?

Yes. The report queries Cisco's openVuln API with the version string normalised to the form that API accepts.

What about advisories that match the version but not the hardware?

They are marked platform mismatch, sorted below the confirmed matches, and kept out of the confirmed High, Medium and Low counts. An advisory with no product data is called out and is not treated as a clean pass.

Does it check non-Cisco or ASA devices?

Non-Cisco devices are skipped. Security Audit is not supported on Cisco ASA. The report is for Cisco IOS, IOS-XE and NX-OS.

Can I export or email the report?

Yes. There is an Export CSV button above each table, and you can email the report. If the email is skipped, the log says why.
