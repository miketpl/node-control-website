Palo Alto PAN-OS firewall rule analyser

The Firewall Rule Analyser in Node Control is a built-in policy inspector for PAN-OS. It sits in Professional, at £25 a month or £255 a year, with no per-device fees. It is not in the Free Edition. In the 14-day trial it shows a clickable example view, but it does not run until Professional.

You can still start a 14-day trial, with no card needed, for the Engineer tasks and reports, including L3 and WAN maps and the Security Audit. Monitor, IPAM, the Meraki Configurator, Discover and the Firewall Analyser show clickable example views in the trial, but they are not operational until Professional. After 14 days, Free stays for up to 25 devices. To run the analyser itself, you need Professional.

Engineers often search for a Palo Alto rule analyzer when they mean this job: take a PAN-OS rulebase, check it against your own standards, compare it with an earlier policy, and try a proposed rule before anyone commits it.

The problem a rule review has to solve

A PAN-OS rulebase is easy to grow and hard to read back. Wide rules, missing logging, weak names and forgotten services sit next to the rules you meant to write. You want a review on your laptop, against standards you control, including a pull from Panorama and a comparison with the last policy you stored.

How Node Control does it

The Firewall Rule Analyser is its own tab on Professional. You can load a config file or pull the running config from Panorama, edit your standards, and run Analyse. The inner tabs are Rulebase Analyser, Compare, and Proposed Rule Tester.

Edit Standards opens a YAML editor, with Reset to Default. The checks include naming and ticket patterns, required logging, limits on source and destination host counts and on port breadth, a flag for any-any rules, a setting so a destination of any with a URL filtering profile is not scored as wide open, and lists of forbidden services and zone pairs. The default forbidden services are tcp/23, udp/69 and tcp/512-514. The checks are deterministic. An empty or unrecognised export fails clearly; it does not pass every check. There is no picker of named industry standards.

Pull from Panorama fetches the running config and the configuration log over the API. Every pull is stored, the previous pull loads as the baseline, and you pick any stored pull and any device group. Panorama is not a library device type. Compare lists every rule that was added, modified, removed or re-ordered, field by field. Changed By names the admin from the Panorama configuration log, except for a rule that only moved. The Proposed Rule Tester is where you try a rule before you commit it, with object-name autocomplete.

The 14-day trial shows a clickable example view of the analyser, but it does not run until Professional. Built-in AI is available on the same page, with a provider you bring and your own API key. There is no AI subscription and no markup. AI review is ticked by default on the Assess row; AI advisory is shown as well. The deterministic findings do not need a provider.

What you get

A Palo Alto / PAN-OS firewall rule analyser in a desktop app for macOS and Windows: editable standards, a Panorama pull with stored baselines, policy compare, and a Proposed Rule Tester. Professional is £25 a month or £255 a year, with no per-device fees. The analyser is a review and testing tool. It does not replace Panorama, and it does not promise a named-standards report.

Requirements and supported platforms

The app runs on macOS and Windows. The analyser is a PAN-OS tool on Professional and on the AI edition, which is not yet available to buy. Free does not show the tab. In the 14-day trial it shows a clickable example view, but it does not run until Professional. You can load a config file or pull from Panorama. Individual firewalls are managed in the library; Panorama is not a library device type.

FAQ

Is the Firewall Analyser in the 14-day trial?

The trial shows a clickable example view. The analyser does not run until Professional. The trial still includes the Engineer tasks and reports.

Is this only for Palo Alto PAN-OS?

Yes. The documentation describes it as a PAN-OS tool. This page does not claim other firewall vendors.

Can I pull policies from Panorama?

Yes. Pull from Panorama fetches the running config and the configuration log, stores every pull, and lets you pick a stored pull and a device group. Panorama is not supported as a device in the library.

Does it flag any-any rules?

Yes, when that flag is set in your standards. A destination of any with a URL filtering profile is not scored as wide open.

Can I test a rule before it is committed?

Yes. The Proposed Rule Tester is for trying a rule before you commit it anywhere. Object names autocomplete on the fields.
