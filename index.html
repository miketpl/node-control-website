What it does

Free Edition is the work that is not marked Pro: an L2 map, config backup, Find Device, an inventory report, and file transfer, for up to 25 devices. Cards marked Pro are Professional.

Network Discovery Pro

Give it a seed IP. CDP, LLDP, and SNMP walk the neighbours and build an inventory. Seed-IP discovery is Professional.

L2 / L3 / WAN Topology

Free Edition draws the L2 map. L3 and WAN maps are Professional Pro. Right-click a node for SSH, ping, traceroute, or a table lookup.

Push Config at Scale Pro

Broadcast commands to the fleet or to one device. Safe mode, config mode, and a dry run. Push at scale is Professional.

Scheduled backups Pro

Scheduled config backups, diffs, and repeatable tasks. Professional. Config Backup and Save Config are in Free Edition.

Terminal

Free Edition includes a multi-vendor terminal. Open a session to a device in the library from the laptop.

API Explorer Pro

Call Meraki, Catalyst Center, PAN-OS, and Cisco ISE from the app and read the response in place. Professional.
